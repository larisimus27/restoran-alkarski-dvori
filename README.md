# Alkarski dvori – Sinj

Gastro vodič restorana Alkarski dvori smještenog u srcu Sinja. Web stranica predstavlja tradicijsku dalmatinsku kuhinju, nudi pregled jelovnika s jelima i pićima, recept za peku ispod peke te mogućnost rezervacije stola.

## Live demo

https://restoran-alkarski-dvori.netlify.app

## Stranice

- index.html – Naslovnica
- jelovnik.html – Jelovnik (jela i pića s filterom po kategoriji)
- recepti.html – Recept: Peka ispod peke
- rezervacija.html – Forma za rezervaciju stola

## Tehnologije

HTML5, CSS3 (Flexbox, CSS varijable), JavaScript (vanilla)  
Google Analytics 4, Netlify hosting
